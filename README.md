# Semantic HTML Personal Profile

This repository contains an introductory HTML assignment: a multi-section personal page about Jamal Oladele's interests in artificial intelligence, software development, and reliable AI systems.

## Assignment requirements demonstrated

- Valid HTML document structure with `<!DOCTYPE html>`, `html`, `head`, `title`, and `body`
- Meaningful semantic elements, including `header`, `nav`, `main`, `section`, `article`, `figure`, and `footer`
- One `h1` page title followed by logically nested `h2` section headings and `h3` subsection headings
- A technology illustration embedded with an `img` element and descriptive alternative text
- Unordered lists for the navigation menu and technical skills

## Repository files

- `index.html` - the semantic personal profile page
- `profile-illustration.svg` - the accessible AI and software-development illustration

## Viewing the page

Download or clone the repository, then open `index.html` in a web browser. The assignment intentionally uses no CSS so the focus remains on HTML structure and meaning.
